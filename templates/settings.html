Settings

Saved to a local SQLite database in data/, so everything survives a restart. That folder is gitignored — your key and webhooks never leave this machine.

🎟️ Tickets webhook (primary)

Where ticket-release announcements get posted.

🎥 Upcoming movies webhook

Where the “who has tickets” posts go.

🔑 TMDB API key

Powers movie search, posters, synopses and trailers. Generate your own key at themoviedb.org → Both the v3 API key and the v4 read access token work.

📅 Calendar

Subscribe your phone or desktop calendar to this link and every movie night and ticket drop shows up automatically, updating whenever you change one. Each entry also has its own 📅 Calendar button for a one-off download.

iPhone: Calendar → Calendars → Add Calendar → Add Subscription Calendar. Google Calendar: Other calendars → From URL. Both need to reach this machine, so use it on your home network (or over a VPN).

🔄 Updates

Pulls the latest code from GitHub and restarts itself. Your database is never touched by an update.
