🏷️ Finding a forum tag ID

Turn on Developer Mode first: Discord → Settings → Advanced → Developer Mode.

Then open your forum channel, right-click the tag in the tag bar along the top (or in the tag list when creating a post) and choose Copy Tag ID. Paste it here.

If your Discord build has no “Copy Tag ID”, post once in the forum by hand with the tag applied, then open that post in the browser client — the tag ID appears in the address bar as ?tag=… when you filter the forum by it.

Tags are per-channel. An ID from a different forum will be rejected, and the Send test message button will tell you so.

🎨 Embed colour

The stripe down the left of every Discord post is taken from the movie's poster. Pick how. Changing this recolours your saved movies in the background — posts already on Discord keep their stripe until you re-post or edit them.

📅 Calendar

Subscribe your phone or desktop calendar to this link and every movie night and ticket drop shows up automatically, updating whenever you change one. Each entry also has its own 📅 Calendar button for a one-off download.

iPhone: Calendar → Calendars → Add Calendar → Add Subscription Calendar. Google Calendar: Other calendars → From URL. Both need to reach this machine, so use it on your home network (or over a VPN).
